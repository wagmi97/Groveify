## Introduction

Welcome to Groveify! This repository contains the source code and documentation for Groveify, a project made for the DevSoc Training Program. Groveify provides users with an interactive and visually appealing way to engage with productivity through an AI-powered isometric map that grows as they complete tasks.

Groveify combines artificial intelligence with **quantum computing technology** to explore advanced approaches to productivity, optimization, and intelligent task management.

### AI-Powered Productivity

Groveify leverages AI to enhance the productivity experience, combining intelligent workflows with a dynamic visual environment that evolves as users accomplish their goals.

### Quantum Computing Integration

Groveify incorporates **quantum computing technology** to explore advanced computational approaches to productivity and optimization. Quantum algorithms can be applied to complex problems involving task scheduling, prioritization, and resource allocation.

By combining quantum computing with AI-powered productivity tools, Groveify explores the potential of quantum computation to enhance intelligent decision-making and personalized productivity.

## Installation

To run this project locally, follow these steps:

1. **Clone the Repository**

   ```bash
   git clone git@github.com:wagmi97/trainee-earth-24t1.git
   cd groveify
   ```

2. **Run the Frontend**

   ```bash
   cd frontend
   npm run dev
   ```

3. **Run the Backend (in a different terminal)**

   ```bash
   cd backend
   npm run dev
   ```
